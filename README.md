# pi-ming-voice

给 Pi Coding Agent 增加语音输入：输入 `/voice` 或按快捷键开始录音，再次触发结束录音，通过 Ming-3.0-asr-tiny 转写后填回输入框。

当前阶段：**工作区与实现计划已建立，插件尚未实现，也未完成麦克风或 API 实测**。

## 第一版体验

1. 在 Pi 终端中输入 `/voice`，或按用户配置的快捷键
2. 底部显示录音状态和时长，对着麦克风说需求
3. 再次触发结束录音，显示识别状态
4. 转写追加到现有输入框，用户可以修改，再按 Enter 发送
5. 录音时按 Esc 可以取消

第一版面向 Windows 11 的交互式 Pi CLI。快捷键方案须经真实终端验证，具体默认组合尚未确定。

## 开发状态

本仓库暂时只有文档，不提供安装命令、可运行插件或已完成能力声明。后续按 PLAN.md 推进，先验证录音与 Pi 交互，再实现与测试闭环。

拟采用 TypeScript 的 Pi extension。Ming 走云端 API；本地负责麦克风采集，第一候选录音后端为 FFmpeg。第一版不包含 TTS、音频问答或 Pi Agent Desktop 界面集成。
